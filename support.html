Support

Help, bug reports, and feature requests for DuoOnAir.

In short: found a bug or have an idea? Open an issue on this site's GitHub page. For anything private, email support@halans.dev.

Submit an issue on GitHub

Bug reports, feature requests, and questions are all tracked as issues in the GitHub repository for this site. You need a free GitHub account to post one.

Open a new issue

Or browse existing issues first. Someone may have already reported the same thing, and you can add to it.

What to include

A good report gets fixed faster. Please tell us:

  • what you expected to happen and what happened instead;
  • the steps to reproduce it;
  • your iPhone model, iOS version, and DuoOnAir version;
  • a screenshot or screen recording, if it helps.

Keep it private

GitHub issues are public. Don't include personal information such as your email address, phone number, or anything else you wouldn't want others to see. If your problem involves something private, email support@halans.dev instead.

Other ways to reach us

You can always email support@halans.dev with questions or feedback. See also the privacy policy.
